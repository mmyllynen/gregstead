# Contributing

Bug reports, reproduction cases, documentation and focused fixes are welcome.
Use the [main Gregstead issue tracker](https://github.com/mmyllynen/gregstead/issues)
for the modpack, its ports and its custom mods.

For a bug report, include:

- Minecraft, NeoForge and Gregstead/component versions.
- Steps to reproduce, expected behavior and what actually happened.
- Relevant logs or crash reports, with credentials and private details removed.
- Whether it also happens in a fresh world or with the smallest relevant mod set.

For a pull request, explain the problem, keep the change focused, and describe
how you tested it. AI-assisted contributions are welcome; disclose their use
and review the result yourself. You are responsible for what you submit.

Preserve existing registry IDs and save compatibility unless a migration is
explicitly part of the change. Retain original author credits and licenses.
See [BUILDING.md](BUILDING.md) for building the components.

Report issues specific to this port here, rather than asking upstream authors
to support it. Report an upstream issue there only after reproducing it in an
official upstream version without this port.

# Gregstead

Gregstead is a custom Minecraft 26.3 modpack built around unofficial ports of
GregTech CE Unofficial (GTCEu) and EMI, alongside some of my favorite mods and
custom additions. It uses NeoForge 26.3.0.77 and Java 25.

## The idea

I'm aiming for a loose balance between survival and creative building:

- Mobs are still there, but Calm Crystals and the Calm Amulet can give you some
  peace. Protection is local, has exceptions, and doesn't mean you can attack
  mobs without consequences.
- Need bulk building materials? The Altar of Abundance trades a diamond and an
  eligible raw material block for a stack of that material.
- GregTech provides the technology progression; the other mods add exploration,
  storage, building options and everyday conveniences.

There is no questbook, and there probably never will be. Never say never.

## Downloads and support

This is the main repository and support channel for Gregstead and its individual
mods. Use [GitHub releases](https://github.com/mmyllynen/gregstead/releases) for
available files and [GitHub issues](https://github.com/mmyllynen/gregstead/issues)
for bug reports. The CurseForge modpack page will be linked here when available.

The initial tested platform is Linux. Windows and macOS have not been validated.
Individual mods are available separately where their dependencies permit; see
[MODLIST.md](MODLIST.md) for the required companions and client/server placement.
